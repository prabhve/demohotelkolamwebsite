# Hotel Kolam | Boutique Stay in Prince Chowk, Dehradun

Official web application and direct booking portal for **Hotel Kolam** (Townhouse Hotel Kolam), located at Plot No. 36, Raja Road, Near Prince Chowk, Central Dehradun, Uttarakhand.

## 🌟 Key Features

- **Direct Booking Engine & Rate Calculator**: Live room pricing, date picker, guest selection, addon selection (Himalayan breakfast buffet, airport shuttle, early check-in, extra bed), and automatic 15% discount with promo code `KOLAM15`.
- **Instant Voucher & WhatsApp Dispatch**: Generates a confirmed booking voucher with 1-click WhatsApp concierge messaging and print capabilities.
- **Accommodations & Room Explorer**: Filterable room categories (*Classic Deluxe, Executive Balcony, Himalayan View Superior, Royal Family Suite*) with detailed room specs, floor area, bed types, and amenities.
- **The Kolam Diner**: Interactive menu showcasing Garhwali Pahadi specialties (*Aloo ke Gutke, Mandua Roti, Kumaoni Dal*), North Indian mains, breakfast combos, and in-room dining bill tray calculator.
- **Dehradun & Mussoorie Sightseeing Guide**: Curated attractions with actual distances from Prince Chowk and instant sightseeing cab booking assist.
- **Interactive Google Maps**: Real coordinates (`30.3170283, 78.0364608`), direct Google Maps route button, and transit guides (0.6 km from Railway Station, 26 km from Jolly Grant Airport).
- **Guest Reviews & FAQs**: Real reviews breakdown and accordion FAQs.
- **Full Responsive Design**: Fluid layout for desktop, laptop, tablet, and mobile screens.

## 🚀 Deployment to Vercel

1. Push this repository to **GitHub**.
2. Go to [Vercel Dashboard](https://vercel.com/new) and select **Import Git Repository**.
3. Framework Preset: **Vite**
4. Build Command: `npm run build`
5. Output Directory: `dist`
6. Click **Deploy**.

## 🛠 Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
